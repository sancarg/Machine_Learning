# Clustering Projects

This directory contains a collection of unsupervised learning projects focused on clustering and segmentation. Each project explores a different dataset and demonstrates how clustering can reveal hidden patterns in real-world data.

## Projects Included

- Customer Segmentation Analysis  
  This project clusters mall customers based on age, annual income, and spending score to identify customer groups and business opportunities.

- Military Power Clustering  
  This project groups countries according to military capability indicators, highlighting patterns in global defense strength.

## What These Projects Showcase

- Exploratory Data Analysis (EDA)
- Data preprocessing and feature preparation
- K-Means clustering
- Hierarchical clustering
- Cluster interpretation and visualization
- Application of machine learning to real-world problems

## Purpose

These projects help build a strong foundation in unsupervised learning and demonstrate how clustering can be used for both business and strategic analysis.

Additional clustering projects and case studies will be added here as this portfolio grows.
