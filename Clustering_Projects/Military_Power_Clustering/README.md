# Military Power Clustering

This project analyzes global military strength using clustering techniques to group countries based on military-related indicators.

## Objective
Identify patterns in military capability and classify countries into meaningful groups based on their defense profile.

## Dataset
The project uses the dataset:
- `World military power.xlsx`

It includes variables related to:
- military spending
- personnel strength
- air, land, and naval power
- defense capabilities

## Methods Used
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature selection
- K-Means clustering
- Cluster visualization and interpretation

## Tools
- Python
- pandas
- NumPy
- matplotlib
- seaborn
- scikit-learn

## Notebook
- `Military_Power_Clustering.ipynb`

## Outcome
The project helps reveal how countries can be grouped according to their military strength and strategic capabilities, providing a useful unsupervised learning example in a geopolitical context.

## Summary
This project demonstrates how clustering can be applied to real-world strategic data to uncover hidden patterns and group countries by military power.
