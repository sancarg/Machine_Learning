# Customer Segmentation with Clustering

This project applies unsupervised learning to segment customers based on their buying behavior and demographic data.

## Objective
Identify meaningful customer groups using clustering techniques and interpret them for business use.

## Dataset
The project uses the Mall Customers dataset with:
- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

## Workflow
- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Feature selection
- K-Means clustering
- Hierarchical clustering
- Cluster visualization and labeling

## Tools
- Python
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn
- pyclustertend

## Key Idea
Customers are grouped according to patterns in:
- age
- income
- spending behavior

This allows businesses to better understand customer segments and design marketing strategies.

## Result
The notebook demonstrates how to:
- analyze customer patterns
- determine the best number of clusters
- apply clustering algorithms
- interpret customer groups
